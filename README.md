# Power-BI-Sales-Analysis-Dashboard
This project demonstrates how raw online sales data can be transformed into actionable insights using Microsoft Power BI.

🔎 **Project Objective**
To build an interactive and user-friendly dashboard that helps analyze sales data, identify trends, and support data-driven decision making.
Key Features
✅ Interactive Dashboard to track and analyze online sales performance.
✅ Complex Parameters & Drill-Downs with filters and slicers for dynamic exploration.
✅ Data Modeling – connections, joins, and calculated fields to manipulate data and enable user-driven analysis.
✅ Customized Visualizations including:
  -Bar Chart
  -Pie Chart
  -Donut Chart
  -Clustered Bar Chart
  -Scatter Plot
  -Line Chart
  -Area Chart

**Outcome**
- Delivered a visually appealing, interactive dashboard.
- Simplified complex datasets into clear, actionable insights.
- Uncovered key sales trends, customer behavior patterns, and growth opportunities.

**Tools Used**
-Microsoft Power BI
-Data Modeling (Joins, Relationships, Calculated Columns & Measures)
-DAX Functions.
